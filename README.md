# 💪 B1nHYu 训练手册 / Training & Diet Planner

A free, mobile-first web app for **strength training and diet planning**, built as a single static HTML page and hosted on GitHub Pages.

🔗 **Live site:** https://b1nhyu.github.io

## ✨ 功能 / Features

- 🏋️ **三分化训练 (3-day split)** – plan and log daily workouts, with training suggestions for the day
- 🔄 **碳水循环 (carb cycling)** – diet planning that adjusts carbohydrates by training day
- 🔍 **食物库搜索 (food database search)** – look up foods and add them to your meals
- 🏃 **运动专项 (sport-specific training)** – record specialised training sessions
- ✍️ **自由训练 (free workouts)** – log sessions that are not part of the plan
- 🌗 **Light / dark mode** – follows the system theme automatically
- 💾 **Saved in your browser** – data is stored with `localStorage`, so no account or server is needed

## 🛠️ Tech Stack

- HTML, CSS and vanilla JavaScript in a single `index.html` file (no frameworks or build step)
- Mobile-app style interface: bottom tab bar, bottom sheets and card layout
- Responsive layout for phones, with safe-area support
- Hosted on **GitHub Pages**

## 🚀 Run Locally

No installation is required.

```bash
git clone https://github.com/B1nHYu/B1nHYu.github.io.git
cd B1nHYu.github.io
```

Then open `index.html` in your browser (or serve it with any static server, for example `npx serve`).

## 📱 Tip

Open the site on your phone and choose **Add to Home Screen** to use it like an app.
